# MemoryMigrator MVP - 用户故事 (User Stories)

## 产品背景
- **产品名**: MemoryMigrator (记忆迁移官)
- **核心功能**: 将用户在 ChatGPT/Claude 的历史对话、知识库、偏好导出为提示词，导入 OpenClaw
- **定价**: $5/次
- **平台**: Web (初期)

---

## Epic 1: 文件上传与解析

### User Story 1.1: 用户上传 ChatGPT 导出文件
**作为** 用户
**我想** 上传 ChatGPT 导出的 JSON 文件
**以便** 系统能够解析并提取对话内容

**验收标准**:
- [ ] 用户可以通过拖拽或点击上传文件
- [ ] 系统接受 .json 格式文件
- [ ] 文件大小限制为 10MB
- [ ] 上传成功显示文件名和大小
- [ ] 上传失败显示错误信息

### User Story 1.2: 解析 ChatGPT 导出 JSON
**作为** 系统
**我想** 解析 ChatGPT 导出的 JSON 格式
**以便** 提取对话内容

**验收标准**:
- [ ] 正确解析 ChatGPT JSON 格式
- [ ] 提取所有对话消息（role: user/assistant）
- [ ] 提取消息创建时间
- [ ] 解析失败返回友好错误信息

### User Story 1.3: 支持 Claude 导出格式
**作为** 用户
**我想** 上传 Claude 对话记录
**以便** 系统能够解析 Claude 格式

**验收标准**:
- [ ] 支持 Claude 复制对话的文本格式
- [ ] 能够从文本中提取对话轮次
- [ ] 正确识别用户和 AI 的发言

## Epic 2: AI 智能摘要

### User Story 2.1: AI 生成对话摘要
**作为** 系统
**我想** 使用 GPT-4o 分析对话并生成结构化摘要
**以便** 提取关键信息

**验收标准**:
- [ ] 调用 OpenAI API 生成摘要
- [ ] 提取用户核心需求/问题
- [ ] 提取 AI 的解决方案/回答
- [ ] 提取用户偏好(语气、格式、角色)
- [ ] 提取关键知识点
- [ ] 提取后续行动计划

### User Story 2.2: 用户预览和编辑摘要
**作为** 用户
**我想** 预览 AI 生成的摘要并手动编辑
**以便** 确保信息准确

**验收标准**:
- [ ] 显示 AI 生成的摘要内容
- [ ] 支持用户编辑摘要内容
- [ ] 保存用户编辑后的内容

## Epic 3: 提示词生成

### User Story 3.1: 生成 OpenClaw 提示词
**作为** 系统
**我想** 根据摘要生成 OpenClaw 可用的提示词
**以便** 用户可以直接导入

**验收标准**:
- [ ] 生成 Markdown 格式提示词
- [ ] 包含对话摘要
- [ ] 包含用户偏好设置
- [ ] 包含关键知识点
- [ ] 格式规范易读

### User Story 3.2: 生成 OpenClaw Skill 文件
**作为** 系统
**我想** 生成可直接加载的 Skill JSON 文件
**以便** 用户一键导入

**验收标准**:
- [ ] 生成符合 OpenClaw 格式的 Skill JSON
- [ ] 包含 name、description、instructions
- [ ] 用户可下载 Skill 文件

### User Story 3.3: 导出功能
**作为** 用户
**我想** 下载生成的提示词和 Skill 文件
**以便** 导入到 OpenClaw

**验收标准**:
- [ ] 支持复制提示词到剪贴板
- [ ] 支持下载提示词为 .md 文件
- [ ] 支持下载 Skill 为 .json 文件

## 技术约束

1. **KISS 原则**: 保持代码简洁，避免过度设计
2. **高内聚低耦合**: 每个模块职责单一，模块间通过接口通信
3. **测试覆盖**: 所有功能代码必须有对应测试
4. **不影响其他功能**: 新功能不影响已有功能
