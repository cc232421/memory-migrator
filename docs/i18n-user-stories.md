# i18n 国际化系统 - 用户故事 (User Stories)

## 产品背景
- **产品名**: MemoryMigrator i18n System
- **核心功能**: 支持英文和中文两种语言，默认英文
- **目标用户**: 全球用户 (英文为主，中国用户支持中文)

---

## Epic 1: 国际化基础架构

### User Story 1.1: i18n 配置文件
**作为** 开发者
**我想** 建立国际化配置文件
**以便** 管理所有翻译文本

**验收标准**:
- [ ] 有英文翻译文件 (en.json)
- [ ] 有中文翻译文件 (zh.json)
- [ ] 包含所有页面常用文本
- [ ] 支持嵌套结构

### User Story 1.2: 语言切换组件
**作为** 用户
**我想** 切换页面语言
**以便** 用母语浏览内容

**验收标准**:
- [ ] 导航栏有语言切换按钮
- [ ] 点击切换按钮切换语言
- [ ] 语言状态持久化 (localStorage)
- [ ] 切换后页面立即更新

### User Story 1.3: 自动语言检测
**作为** 系统
**我想** 根据用户浏览器自动选择语言
**以便** 提供更好的用户体验

**验收标准**:
- [ ] 检测浏览器首选语言
- [ ] 中文浏览器显示中文
- [ ] 英文浏览器显示英文

---

## Epic 2: 页面内容国际化

### User Story 2.1: 导航栏国际化
**作为** 用户
**我想** 导航栏显示当前语言
**以便** 知道当前语言状态

**验收标准**:
- [ ] 首页导航显示英文
- [ ] 教程导航显示英文
- [ ] 定价导航显示英文
- [ ] 上传导航显示英文

### User Story 2.2: 教程页面国际化
**作为** 用户
**我想** 用母语查看教程
**以便** 更容易理解操作步骤

**验收标准**:
- [ ] /guide 教程首页英文版
- [ ] /guide/quick-start 快速开始英文版
- [ ] /guide/chatgpt ChatGPT教程英文版
- [ ] /guide/faq 常见问题英文版
- [ ] 所有教程中文版

### User Story 2.3: 其他页面国际化
**作为** 用户
**我想** 所有页面都能切换语言
**以便** 完整使用产品

**验收标准**:
- [ ] / (首页) 英文版
- [ ] /pricing (定价) 英文版
- [ ] /upload (上传) 英文版
- [ ] /how-it-works (操作指南) 英文版

---

## Epic 3: 语言持久化

### User Story 3.1: 语言设置保存
**作为** 用户
**我想** 我的语言选择被记住
**以便** 再次访问时不需要重新选择

**验收标准**:
- [ ] 语言设置保存在 localStorage
- [ ] 刷新页面保持语言设置
- [ ] 新窗口也应用语言设置

## 技术方案

使用 `next-i18next` 或自定义 i18n hook 实现：

```
src/
├── i18n/
│   ├── config.ts       # i18n 配置
│   ├── locales/
│   │   ├── en.json    # 英文翻译
│   │   └── zh.json    # 中文翻译
│   └── useTranslation.ts  # 自定义 hook
```

---

## 默认语言

- **默认语言**: 英文 (en)
- **备用语言**: 中文 (zh)
- **检测顺序**: localStorage > Browser > en
