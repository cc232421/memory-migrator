# 教程系统用户故事 (User Stories)

## 产品背景
- **产品名**: MemoryMigrator 教程系统
- **核心功能**: 详细的新手操作指南，让零经验用户也能完成 AI 对话导出
- **目标用户**: 新手小白、第一次使用导出工具的用户

---

## Epic 1: 教程导航

### User Story 1.1: 教程入口
**作为** 访客
**我想** 在网站上找到教程入口
**以便** 了解如何使用工具

**验收标准**:
- [ ] 顶部导航有"教程"按钮
- [ ] 点击教程按钮进入 /guide 页面
- [ ] 首页有教程快速链接

### User Story 1.2: 教程首页
**作为** 用户
**我想** 看到教程概览
**以便** 知道自己需要做什么

**验收标准**:
- [ ] 显示"快速开始"入口
- [ ] 显示各平台教程列表
- [ ] 显示 FAQ 入口

---

## Epic 2: 快速开始

### User Story 2.1: 快速开始页面
**作为** 新手
**我想** 用3分钟完成整个流程
**以便** 快速体验工具

**验收标准**:
- [ ] 显示3个步骤说明
- [ ] 每步有明确操作指引
- [ ] 每步有"完成后验证"提示
- [ ] 包含"太复杂？去详细教程"链接

---

## 技术约束

1. **KISS 原则**: 每个组件简单独立
2. **高内聚低耦合**: 教程数据与组件分离
3. **100% 测试覆盖**: 所有新增代码
4. **不影响现有功能**: 新页面与旧代码解耦
